<summary><h3>☯ Everything is code and all code is plain text</h3></summary>

Keep your Universe in plain text.

**_Plain text_ is future-proof!**
    
I've been using computers since the early 90s, and all these years I've been struggling with locked data. Apps trying to lock my data in a proprietary format... Clouds trying to hijack control of my data... Being unable to work with legacy stuff because no program can open it anymore...

But it seems UNIX solved it a long time ago, and all I had to do was accept that part of UNIX philosophy.

_Use plain text whenever you can:_

* It is timeless
* It is universal
* It is accepted by most of the tools
* You can treat it as code in version control with all the benefits
    * versioning
    * branching
    * merges
    * reviews
    * backups
    * rollbacks.
* It forces you to use simple tools and think clearly

So instead of locking my notes in proprietary clouds, I'd rather use simple plain text files. There are multiple ways to sync plain-text notes and keep them accessible.

After many years of proprietary blogging platforms and hosting my own WordPress, I finally settled on plain Markdown with a static site generator.

Instead of locking my tasks in a proprietary tool, I use plaintext files with to-do lists in my project repositories.

**_Plain text_ is the king!**
