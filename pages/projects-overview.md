Here are some notable examples of games, tools, utilities, and prototypes I've created over the last 30+ years of programming.



## 🎳 Collider.JAM Game Framework

The main [repo](https://github.com/invadium/collider.jam) is just a command shell and packager that glues everything together.

The most interesting parts, like the actual framework's core and essential tools, are found in related repositories:

* [collider.mix](https://github.com/invadium/collider.mix) - the core and essential libraries
* [collider-dev.mix](https://github.com/invadium/collider-dev.mix) - development tools and help system



## 🎲 Games

* [Telemetry Troubles](https://github.com/invadium/telemetry-troubles.mix) - a true space horror where you have to debug assembly code for remote space probes - [PLAY 🎮](https://invadium.itch.io/telemetry-troubles)

* [Z-Alert: Anti-Ballistix](https://github.com/invadium/anti-ballistix.mix) - I'm a compulsive air raid alert coder, and when missile and drone explosions are not too close, I usually start a coding session for this game.

* [Jump'n Loop](https://github.com/invadium/jump-n-loop.mod.git) - a rhythm-jumping game created for Ludum Dare 47 - [PLAY 🎮](https://invadium.itch.io/jump-n-loop)

* [Enceladus Dockyards Boy](https://github.com/invadium/enceladus-dockyards-boy.mix) - a retro-styled game created for Game Boy Jam 2020 - [PLAY 🎮](https://invadium.itch.io/enceladus-dockyards-boy)
 
* [300 Hearts for Escape](https://github.com/invadium/300-hearts-for-escape) - You have to escape a plagued island, trading with your own health points. Created for Ludum Dare 44 (Theme: "Your life is currency") - [PLAY 🎮](https://invadium.itch.io/300-hearts-for-escape)

* [Dronepolis - the City of Lost Drones](https://github.com/invadium/dronepolis) - a 13-kilobyte 3D hovercraft shotter created for js13k competition in 2017 - [PLAY 🎮](https://invadium.itch.io/dronepolis)

* [Alarm 1202](https://github.com/invadium/alarm-1202.mod.git) - a computer on your lunar lander has failed, and now you have to land in manual mode by doing basic arithmetic - [PLAY 🎮](https://invadium.itch.io/alarm-1202)
